# Contributing to macOS-byGEMINI

## Local setup

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

## Quality checks

Before opening a pull request, run the project's available checks and make sure the production build succeeds:

```bash
npm run lint
npm run build
```

For UI changes, include a short description of the affected flow and screenshots when useful. Keep commits focused so they are easy to review.
